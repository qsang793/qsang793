# The profile is written for the community, not for recruiters

The profile speaks first to fellow developers and friends, so personality (the 死に戻り theme, the City, the anime) leads and the README has no "Selected work" section. The work is shown by the six pinned repos and LinkedIn lives in the sidebar, not the README. A Nov 2026 audit recommended a recruiter-first "Midnight Minimal" rewrite; we kept the identity and adopted only its fixes for build reliability, mobile reading and page weight.
